
# FloodNet Dataset Documentation

## Dataset Name
FloodNet: Street Flooding Events Measured by FloodNet Sensors

## Dataset Source
NYC Open Data

## Dataset URL
https://data.cityofnewyork.us/Environment/FloodNet-Street-Flooding-Events-Measured-by-FloodN/aq7i-eu5q

## File Name
floodnet_street_flooding.csv

## Format
CSV

## Project Usage
- Data exploration
- Data cleaning
- Flood depth analysis
- Regression modelling
- Flood severity classification

## Geographical Coverage
New York City, USA

## Important Limitation
The dataset contains recorded flooding events.
It does not represent all normal non-flood conditions.

The project predictions will be limited to
the available dataset and its documented scope.
